# 🎨 Background Color Changer

A simple interactive web app built with vanilla JavaScript that lets users change the page's background color by clicking buttons — including a random color option.

## Features
- 4 fixed color buttons (Red, Green, Blue, Yellow)
- 1 random color button (never repeats the current color)
- Reset button
- Heading dynamically displays the current color name
- Smooth color transitions via CSS

## Concepts Practiced
- DOM selection (`querySelector`)
- Event listeners (`addEventListener`)
- Style manipulation (`.style.property`)
- Arrays and loops (DRY refactoring)
- `Math.random()` and `Math.floor()` for randomness
- `while` loop for retry logic
